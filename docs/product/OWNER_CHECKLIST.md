# 운영자에게 필요한 확인

## 실제 사용자로 확인
- 배포 후 휴대폰에서 구글 로그인 → 식당 저장 → 새로고침 → 저장 목록 확인.
- 위치 권한을 허용하고 주변 결과가 실제 동네와 맞는지 확인.
- 실제 식사 경험으로 방문·포장·배달 중 맞는 방식을 선택해 리뷰 작성.
- 문제가 있으면 화면 문구와 발생 순서를 전달. 비밀번호나 비밀키는 보내지 않는다.

## 운영 결정
- 첫 리뷰를 모을 동네 한 곳을 선택.
- 초기 사용자에게 실제 식사 후기를 요청.
- 문의를 받을 이메일과 신고를 확인할 담당자를 결정.

## 개발 측 확인 사항
- 로컬 빌드에서 BETTER_AUTH_SECRET 기본값 오류가 관찰됨. 운영 설정까지 동일하다는 의미는 아님.
- 기존 CI 근처 테스트의 좌표 없음 조기 종료는 검증 공백이다. 격리된 DB에 좌표 fixture를 넣어 보완해야 함.
- UI 재구축과 근처 찾기 세부 개선은 현재 작업 트리에 있으며 배포 여부와 구분한다.
