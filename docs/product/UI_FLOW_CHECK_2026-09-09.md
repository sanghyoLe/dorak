# 화면·기능 점검

## 수정
- 상세 저장: 로컬 저장 실패 시 선택 상태 복구, 오류 표시, 버튼 재활성화.
- 세션 만료 후 저장 해제: 저장했다는 잘못된 안내 수정.
- 저장 목록: 저장 공간 접근 차단과 삭제 실패 처리.
- 로그인: Google 요청 실패 안내와 재시도, 설정 미완료 문구 정정.
- 로그인 320px: 개인정보 안내 링크 줄바꿈 수정.
- 근처 찾기: 10m 미만 표시, 직선거리·결과 제한 안내, 조회 시간 제한과 재시도.

## 확인
- 타입 검사, 기본 테스트, 프로덕션 빌드 통과.
- 홈·검색·상세·로그인·저장·근처·리뷰 원칙: 320/375/414/768px 넘침·클릭 라벨·명암 검사.
- 상세 저장 공간 오류 복구와 리뷰 작성 앵커·로그인 복귀 주소 확인.
- 저장 목록 접근 차단 오류 표시 확인.
- Google 로그인 요청을 실패 응답으로 대체해 오류 표시·버튼 재활성화 확인.
- 근처 검색 실패 응답 뒤 같은 좌표로 재시도 확인.

## 확인 범위 밖
- 실제 Google 계정 로그인과 로그인 후 리뷰 제출은 실계정 확인 필요.
- 운영 후보가 없어 후보 승인 시각 테스트는 실행하지 않음.
- 좌표 없는 CI 데이터에서 근처 통합 테스트가 조기 종료되는 기존 검증 공백은 별도 보완 필요.
- 로컬 검증 서버에는 임시 인증 시크릿을 사용. 운영 환경 설정 검증을 뜻하지 않음.
- 이번 수정은 커밋·배포 전 작업 트리 상태.
